# Академические презентации в стиле Е. В. Бэкман

Скилл делает презентации на 8–12 слайдов в едином строгом, лаконичном и стильном оформлении. Подходит для отчётов в докторантуре, докладов на конференциях, презентаций курсов, защит и выступлений на семинарах. Язык — русский научный стиль.

## 1. Порядок работы

1. Прочитать все материалы, которые дала пользователь: прикреплённые файлы, ссылки на Google Docs и Slides через подключённый Google Drive, предыдущие презентации. Если тема — диссертация, учесть индивидуальный план и прошлые отчёты.
2. Сверить документы между собой. Найти расхождения: цифры, число компонентов или уровней, названия глав, даты, периоды. Ничего не выдумывать: статистику, цитаты и названия брать только из источников. Если данных нет, оставить плейсхолдер в квадратных скобках.
3. Составить план: одна мысль на слайд, 8–12 слайдов. Типовая структура: титул → исследовательский аппарат или постановка задачи → 2–4 содержательных слайда → данные или эксперимент → публикации и апробация (если уместно) → план или выводы.
4. Сделать презентацию как артефакт типа Slides (Artifact list scope types → Slides) и наполнять файлами в порядке, который задаёт тип: сначала deck.json и титул, затем по три слайда за публикацию.
5. К каждому слайду добавить краткие заметки докладчика в `<aside>`.
6. В ответе: одна строка о результате и список найденных расхождений в документах, нумерованный, с указанием, как это решено на слайдах.
7. Если пользователь попросит текст доклада, создать отдельный Doc: разделы по блокам, внутри «**Слайд N.**» и текст выступления от первого лица (женский род: «выступила», «принимала участие»), примерно минута на слайд, в конце «Благодарю за внимание!».

## 2. Оформление (не менять без просьбы пользователя)

**Шрифты** (faces в deck.json):
- `eb-garamond`: `EB Garamond`, href `https://fonts.googleapis.com/css2?family=EB+Garamond:wght@400..700&display=swap` — заголовки, крупные числа, подписи-акценты.
- `ibm-plex-sans`: `IBM Plex Sans`, href `https://fonts.googleapis.com/css2?family=IBM+Plex+Sans:wght@400;500;600&display=swap` — основной текст.

**Палитра:**
- основной фон `#F6F5F1`; второй кремовый фон (титул, ключевая модель, итоговый слайд) `#ECE9E1`;
- текст `#1B2433`; приглушённый текст `#4F5868`; подписи и номера `#5F6676`;
- акцент (терракота) `#9A3B2E`; градации акцента `#EAD9D3`, `#D9B3A7`, `#C0806E`;
- линии и рамки `#D3CFC4`; более тёмная линия `#C9C4B7`; пунктир неактивного `#B9B4A7`; светлые карточки `#FBFAF7`.
- **Тёмных слайдов нет**: все фоны кремовые.

**Типографская шкала:** 96 (титул) / 64 (заголовок слайда) / 40–48 (подзаголовки, названия в Garamond) / 26–32 (текст) / 24 (подписи, eyebrow, номер слайда). Крупные числа — Garamond 96–112, только для действительно главных показателей.

**Колонтитулы:** никаких подписей «ФИО · название отчёта» внизу. Только номер слайда справа внизу в формате «02 / 10» (не на титуле).

**Иерархия:** второстепенные факты (например, объём библиографии «более 200 источников») не выносить крупными цифрами — только строкой в списке. Крупно — главные результаты: модель, противоречие, публикации, выборка.

## 3. Шаблоны разметки

Секция содержательного слайда:
```html
<section id="ID" data-transition="fade" style="background:#F6F5F1;color:#1B2433;font-family:'IBM Plex Sans', Arial, sans-serif;padding:128px 128px 160px;display:flex;flex-direction:column;gap:48px">
```

Шапка слайда (eyebrow + заголовок):
```html
<div style="display:flex;flex-direction:column;gap:16px">
<p style="font-size:24px;letter-spacing:3px;text-transform:uppercase;color:#9A3B2E;font-weight:600">03 · Название блока</p>
<h2 style="font-family:'EB Garamond', Georgia, serif;font-size:64px;font-weight:500;line-height:1.1;color:#1B2433">Заголовок слайда</h2>
</div>
```

Номер слайда (последний перед `<aside>`):
```html
<p style="position:absolute;right:128px;bottom:64px;width:200px;font-size:24px;color:#5F6676;text-align:right">03 / 10</p>
```

Титул: фон `#ECE9E1`, `padding:128px`, `justify-content:space-between`. Сверху: учреждение (24px, uppercase, акцент) и кафедра (24px, `#5F6676`), справа «Город · год». В центре: блок с `border-left:4px solid #9A3B2E;padding:0 0 0 48px`, h1 Garamond 96px weight 500 и тема 30px `#4F5868` в кавычках-«ёлочках». Внизу: ряд из 3 колонок с `border-top:1px solid #C9C4B7` — подпись 24px `#5F6676` и значение 28px weight 500 (докладчик, научный консультант или руководитель, специальность).

Повторяемые элементы:
- **Строки «метка — текст»** (аппарат исследования, перечни): ряд с `border-top:1px solid #D3CFC4;padding:28px 0 0 0`, слева метка (Garamond 40–44px акцентом или 24px uppercase `#5F6676`, ширина 320–420px), справа текст 28–30px.
- **Выделенный тезис** (противоречие, вывод): `background:#ECE9E1;border-left:4px solid #9A3B2E;padding:36px 48px`, метка 24px uppercase акцентом и текст Garamond 34px.
- **Пилюли** (рамки, ключевые понятия): `p` 26px, `padding:8px 28px;border:1px solid #9A3B2E;border-radius:999px`.
- **Нумерованные компоненты**: строки с `border-top`, номер «01» 24px акцентом, название Garamond 40px.
- **Этапы модели**: ряд из карточек `flex:1`, фон `#F6F5F1` на слайде `#ECE9E1`, `border-top:4px` с усилением акцента от `#D3CFC4` к `#9A3B2E`; над ними линия «от … к …» со стрелкой `x-shape arrow-right`.
- **Статусы глав или задач**: 3 карточки `#FBFAF7` с `border-top:6px` (готово — акцент + `x-icon Check`; в работе — `#1B2433` + `Tool`; запланировано — пунктир `#B9B4A7` + `Clock`).
- **Матрица оценивания**: grid `repeat(N, 76px)`, клетки градациями акцента по уровням.
- **Показатели**: 3–4 блока `flex:1` с `border-top:3px solid #9A3B2E`, число Garamond 112px, подпись 26px.
- **Таблицы** (публикации, план): `font-size:26px`, заголовки `th` цветом `#5F6676`, ширины в % на первой строке.

## 4. Правила текста на слайдах

- Короткие формулировки, без «воды»; тезис вместо маркированного списка, когда возможно.
- Типографика: «ёлочки», длинное тире, неразрывные инициалы «А. В. Хуторской».
- Минимальный кегль 24px; длинные русские слова (например, «операционально-деятельностный») не помещать в узкие карточки — использовать строки на всю ширину.
- Не превышать высоту 824px внутри полей; если не помещается, делить слайд.

## 5. Правки после создания

Править только названные слайды; файлы слайдов редактировать и публиковать только изменённые. Если пользователь просит убрать или ослабить элемент, сохранить общую сетку и стиль.

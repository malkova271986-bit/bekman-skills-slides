# Навык Claude «Академические презентации Е. В. Бэкман»

Навык `academic-slides-bekman` помогает Claude создавать строгие академические презентации в оформлении Е. В. Бэкман (кремовый фон, шрифты EB Garamond и IBM Plex Sans, терракотовый акцент) на любую тему: отчёты, доклады, защиты, выступления на конференциях.

Сам навык — файл [`academic-slides-bekman/SKILL.md`](academic-slides-bekman/SKILL.md).

## Как установить навык в Claude

1. Скачайте папку `academic-slides-bekman` и упакуйте её в ZIP-архив.
2. На claude.ai откройте «Настройки» → «Возможности» (Capabilities) → «Навыки» (Skills).
3. Нажмите «Загрузить навык» и выберите архив.
